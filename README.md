# Cash ERP - نظام تخطيط موارد المؤسسات والمحاسبة (Offline-First)

نظام متكامل للمحاسبة ونقاط البيع (POS) وإدارة المخزون والضرائب، مصمم خصيصاً للعمل في بيئات الاتصال الضعيف أو المنعدم (Offline-First) مع مزامنة سحابية مركزية ومطابقة لمتطلبات السوق المصري.

> [!WARNING]
> **مشروع خاص (Private Repository):**  
> يُحظر تماماً رفع أي ملفات بيئة (`.env` أو `.env.*`)، أو شهادات رقمية ومفاتيح خاصة (`*.pem`, `*.key`)، أو ملفات نسخ احتياطي وتفريغ قواعد بيانات (`*.enc`, `*.dump`).

---

## 1. المتطلبات الأساسية (Prerequisites)
- **Node.js:** v20.0.0 أو أحدث.
- **npm:** v10.0.0 أو أحدث.
- **Git:** مثبت محلياً.

---

## 2. أوامر التشغيل السريعة (Quick Start)

```powershell
# 1. تثبيت الحزم والاعتماديات
npm install

# 2. تشغيل السيرفر المحلي للتطوير (Vite Dev Server)
npm run dev

# 3. فحص الأنواع الصارم (TypeScript No-Emit)
npm run typecheck

# 4. تشغيل الاختبارات المؤتمتة (Vitest - 84 اختباراً)
npm test

# 5. بناء الحزمة الإنتاجية المجمعة (Vite + PWA Workbox)
npm run build

# 6. فحص خلو المشروع من الأسرار والتوكنات المسربة
npm run scan:secrets
```

---

## 3. هيكل المجلدات الرئيسي (Directory Overview)

- **`src/`:** الكود المصدري لتطبيق واجهة المستخدم (React 18 + PWA + Dexie IndexedDB).
- **`supabase/`:** هجرات قاعدة البيانات PostgreSQL 17.11 (`migrations/`) ودوال الحافة (`functions/`) واختبارات SQL (`tests/`).
- **`scripts/`:** سكريبتات الأتمتة والفحص والأمان (سكريبت النسخ الاحتياطي اليومي وفحص الأسرار).
- **`tests/`:** مجموعة اختبارات الوحدة والتكامل المؤتمتة عبر Vitest (13 ملف اختبار).
- **`docs/`:** التوثيق المعماري، المحاسبي، أدلة الهجرة، والقرارات التشغيلية للمنشأة.
