## 5. القواعد الثابتة غير القابلة للكسر (Strict Project Invariants)

1. **توليد المعرفات في جانب العميل (Client-Side UUIDv4):**
   - يتم توليد المعرف الأساسي (`id`) لأي مستند أو بند أو عملية محلياً في المتصفح قبل إرسالها للسيرفر؛ لمنع تضارب المعرفات أثناء العمل أوفلاين.
2. **استخدام مكتبة `decimal.js` حصراً للأرقام المالية:**
   - يُحظر حظراً باتاً استخدام عمليات الحساب الرياضية الافتراضية في جافاسكريبت للأموال أو الضرائب أو الكميات؛ لتفادي أخطاء الفاصلة العائمة.
3. **نافذة المزامنة العائمة 120 ثانية (Floating 120s Pull Window):**
   - عند طلب التحديثات من السيرفر (`sync pull`)، يتم استرجاع السجلات بمؤشر يتراجع بمقدار 120 ثانية عن آخر توقيت مزامنة؛ لمعالجة أي فروقات توقيت دقيقة بين السيرفر والأجهزة وتفادي سقوط المعاملات المتزامنة.
4. **الترقيم المتسلسل المستقل لكل فرع وجهاز:**
   - الترقيم يتبع صيغة مركبة (`series_code` + `seq_no`) مستقلة لكل كاشير (مثل `INV-D1-000001`).
   - عند استعادة نسخة احتياطية قديمة على نفس الجهاز، يُحسب العداد الجديد كالقيمة الأكبر حتماً بين العداد المحلي الحالي وأعلى `seq_no` في النسخة المستعادة، مما يمنع انحدار العدادات وتكرار الأرقام نهائياً.
5. **الحصانة المطلقة للسجلات المعتمدة (Immutability of Posted Documents):**
   - بمجرد اعتماد المستند وتحويل حالته إلى `posted`، يُقفل السجل برمجياً وقاعدياً ويُحظر تعديله أو حذفه، وأي تصحيح يتم عبر مستند عكسي أو إشعار دائن (Credit Note).
6. **عدم المساس بالهجرات 001 إلى 007:**
   - تعديل الهجرات المطبقة محظور قطعياً؛ وأي تغيير جديد يجب أن يكون في هجرة مرقمة جديدة ومستقلة.
7. **انعدام الأسرار في الكود والمستودع:**
   - يُحظر كتابة كلمات المرور، المفاتيح السرية، أو سلاسل الاتصال المباشرة في أي ملف داخل المستودع.

## 6. قائمة الأسئلة المفتوحة والافتراضات التي تتطلب قراراً

### أ. قرارات مالك المنشأة المطلوبة (المفصلة في `docs/decisions_needed.md`):
1. **ربط الفاتورة الإلكترونية الحكومية (ETA):** الخيار المقترح هو تأجيل الربط الفعلي مع إبقاء النظام جاهزاً 100% برمجياً حتى يتم استخراج الختم الإلكتروني والتسجيل الرسمي.
2. **شجرة الحسابات:** اعتماد الهيكل الخماسي المقترح في `docs/chart_of_accounts_proposal.md` كمسودة عمل لحين مراجعتها مع محاسب قانوني.
3. **الخصم التجاري تحت حساب الضريبة (T4):** إبقاء الميزة مغلقة افتراضياً (`Disabled`) في شاشات البيع والشراء اليومية لتسهيل العمل على الكاشير.
4. **النسب الضريبية النشطة:** تفعيل نسبتين فقط في النظام الأساسي (14% للقيمة المضافة المحلية، و 0% للتصدير الخارجي).
5. **سياسة المرتجعات والإلغاء:** اعتماد إصدار إشعار دائن (Credit Note) للفواتير المعتمدة بدلاً من الحذف.
6. **السنة المالية:** اعتماد السنة الميلادية (1 يناير - 31 ديسمبر).
7. **ترقيم الفواتير:** اعتماد بادئة الجهاز والفرع (مثل `INV-D1-xxxxxx`).
8. **الخزائن والبنوك:** إنشاء "خزينة النقدية الرئيسية" و "حساب بنكي رئيسي" كحسابين أوليين في دليل الحسابات.

### ب. فجوات التحقق الميداني الفيزيائي (الموثقة في `docs/known_issues.md`):
- دالة `sync-push` كُتبت واختُبر منطقها بنسبة 100% عبر 11 اختباراً مؤتمتاً، ولكن نشرها الفعلي على شبكة Deno الحية في Supabase لم يُجرَ بعد.
- سلوك Safari على هواتف iPhone عند ترك الجهاز لأكثر من 7 أيام دون فتح (iOS 7-Day Storage Eviction) كُتبت آليات الوقاية منه ومطالبة التثبيت كـ PWA، ولم يُختبر بترك هاتف فيزيائي لأسبوع متواصل.
- تشغيل مهمة الجدولة التلقائية للنسخ السحابي اليومي عبر Windows Task Scheduler يتطلب تثبيت حزمة `pg_dump` على خادم ويندوز الفعلي وتوفير كلمة المرور عبر متغير البيئة الآمن.

## 7. أوامر التشغيل والاختبار وجودة الكود (Commands & Scripts)

كافة الأوامر تعمل عبر سطر الأوامر (PowerShell / Bash) من المجلد الرئيسي `E:/cash`:

```powershell
# 1. تثبيت الحزم والاعتماديات
npm install

npm run build

npm run scan:secrets
```
